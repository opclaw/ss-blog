# Бриф блога Smart Solutions — договорённости с Олегом

Читать перед любой работой над блогом. Если решение противоречит брифу — останавливаемся и спрашиваем Олега.

## Цель
- Блог приводит клиентов на внедрение ИИ: читатель → доверие → бесплатный аудит («Разберём ваш процесс?»).
- Обогнать detistov.ru по запросам вокруг внедрения ИИ.
- Около 60 новых статей и переработка 20 существующих. Приоритеты — `deliverables/BLOG-REWORK-PLAN.md` (по Wordstat, `wordstat-merged.csv`).
- Статьи не должны читаться как «нейрослоп»: у каждой своя структура, живой язык отрасли, польза, которую можно проверить.

## Факты — жёстко
- **Ничего не выдумываем.** Ни кейсов, ни клиентов, ни результатов. Реальные кейсы на сайте только маркетинговые: CND-Store, Arhgrille, Моя Планета.
- Удалены как несуществующие: «агентство с 12 агентами, 35 мин → 47 с» (недвижимость), «клиент купил 20 лицензий за 400 тыс.» (как посчитать эффект).
- Каждая цифра — одно из трёх: ссылка на источник · «пример, подставьте свои» · `[нужно от Олега]`.
- Никаких «в N раз быстрее» в заголовках, никаких «по оценке аналитиков» без ссылки.
- Факты о сторонних сервисах (цены, функции) — только проверенные, с датой проверки.
- Фото автора не нужно (решение Олега).

## Внешний вид — жёстко
- Шапка, меню (Подход · Проекты · Процесс · Услуги · AI · Контакты), подвал, иконки и контакты — **как на живом сайте, не менять**. Они берутся из компонентов `site/src/components`, в статьях своих шапок нет.
- Статья светлая (лист #FAFAF7), шапка и финальный блок контактов тёмные. **Никаких переключателей темы.**
- Цвета только из системы: #00D9FF — графика, #0A7EA4 — текст и ссылки на светлом, зелёный #10B981/#0E9F6E. Шрифты Manrope, Inter, JetBrains Mono.
- Без курсива, без эмодзи, без выдуманного логотипа.
- Порядок статьи, как на сайте: надзаголовок «Тип · AI-направление» → H1 → мета «Олег Кречетов, основатель Smart Solutions · месяц год · ~N минут чтения» → оглавление → текст с рисунками «Рис. N» → «Коротко» в конце → «Частые вопросы» → «Читать дальше» (рубрика · N мин) → «Разберём ваш процесс?».

## Интерактив — чего хочет Олег
- Каждая статья — максимально интерактивная, продуманная, красивая, эстетичная, интересная: движение, визуализации, вкладки, показ процесса. Эталон — «Что такое ИИ-агент» (v6).
- В каждой статье **один главный** интерактив, придуманный под задачу отрасли, и 2–4 поддерживающих. Не одинаковый набор во всех статьях.
- Движение объясняет, а не украшает. Без JS видна статичная версия с тем же смыслом. `prefers-reduced-motion` уважаем.

## Как работаем — командно
Главный редактор (архитектор) · SEO и семантика · маркетинг · контент (автор, редактор «антишаблон», фактчекер) · дизайн (главный дизайнер, инфографик, моушн, интерактив) · разработка · критики-читатели · критики качества · автоматические проверки.
Ворота статьи: SEO → мысль и план → интерактив → текст → факты → сборка → критики → `npm run check` → публикация.
Итог командной работы по статье записывается в `deliverables/articles/<slug>/REVIEW.md`: что решили, что спорили, что исправили.

## Технически
- Сайт — Astro в `site/`. Перед публикацией `npm run check` (сборка, сверка, JS, интерактив).
- Правила CLAUDE.md: без форм и send.php, без cookie-баннера; позиционирование, цены и навигацию главной не меняем без согласия; коммиты conventional; деплой Vercel-превью → Beget.
- Ключи API только через переменные окружения, в репозиторий не коммитим.
