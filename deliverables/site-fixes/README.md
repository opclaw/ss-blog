# Правки для smartsolutions.today — пакет №1

Порядок выкладки: 1 → 2 → 3 → 4. Каждый пункт независим, можно выкладывать по одному.

## 1. robots.txt — заменить целиком
Файл: `robots.txt` → корень сайта.
- Явно разрешены ИИ-поисковики (GPTBot, ClaudeBot, PerplexityBot и др.) — нужно для GEO.
- Для Яндекса добавлен `Clean-param`: страницы с utm-метками и yclid не будут считаться дублями.
- Убрана устаревшая директива `Host` (Яндекс её не использует с 2018 года).

Проверка: Яндекс Вебмастер → Инструменты → Анализ robots.txt.

## 2. sitemap.xml — заменить целиком
Файл: `sitemap.xml` → корень сайта.
- Добавлена новая статья `blog/chto-takoe-ii-agent.html` (выкладывать вместе с ней, п. 4).
- `lastmod` стоит **только у реально изменённых страниц**. Одинаковая дата у всех страниц — сигнал поисковику, что дате верить нельзя. При каждой правке статьи ставим ей новую дату.

После выкладки: Вебмастер → Индексирование → Файлы Sitemap → переотправить; там же «Переобход страниц» для новой статьи.

## 3. Битые ссылки меню в статьях блога
Сейчас в каждой статье `/blog/*.html` пункты «Подход», «Проекты», «Процесс» ведут на `/blog/index.html#approach` — это не главная, якорь не срабатывает.

Найти в шапке каждой статьи и заменить:
| Было | Стало |
|---|---|
| `href="index.html#approach"` | `href="/#approach"` |
| `href="index.html#projects"` | `href="/#projects"` |
| `href="index.html#process"` | `href="/#process"` |

Если есть доступ к файлам по SSH, одной командой в папке `blog/`:
```bash
sed -i 's#href="index.html\#\(approach\|projects\|process\)"#href="/\#\1"#g' *.html
```
Также проверьте ссылку «Позвонить» на ai.html и в блоге: должна быть `tel:+79250909500`.

- `blog/assets/blog.css` и `blog/assets/blog.js` — **общие** стили и скрипт для всех статей. Сейчас стили, видимо, лежат внутри каждой статьи; с общим файлом правка дизайна — одна правка вместо 22.
- `blog/index.html` — новая главная блога (фильтр по рубрикам + поиск, рубрика «ИИ-агенты»).
- `blog/chto-takoe-ii-agent.html` — первая статья в новом дизайне.

Шрифты — системные, без Google Fonts: быстрее грузится в России и не передаёт данные посетителей в Google.

Старые 22 статьи можно переводить в новый дизайн постепенно, по мере переписывания.
