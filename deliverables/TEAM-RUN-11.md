# TEAM-RUN-11. Три команды подряд: релевантность, плотность, чистота + охота за «чёрным»

Дата: 2026-09-27. Область: 21 статья, 58 фигур, 57 интерактивных блоков, 11 таблиц.
Метод: замеры в Chromium по каждому элементу; инструменты — `site/tools/audit-design.mjs`,
`audit-figures.mjs`, `audit-articles.mjs`, `style-check.py`. Роли: три команды (друг за другом),
во главе критик и архитектор/оркестратор.

## 1. Охота за «при увеличении становится чёрным»

Проверено **всё**, где вообще может быть графика:

| Контекст | Результат |
|---|---|
| 58 фигур на 19 страницах (все внутри `.bl-sheet`) | фон увеличения `rgb(250,250,247)` — светлый лист |
| фигуры внутри тёмных блоков (`kit-dark`, `bl-screen`, `bl-cta`) | **0 случаев** — таких фигур в блоге нет |
| статья сама по себе | светлый лист `#FAFAF7`, тёмная только шапка/футер |
| форсированная тёмная тема браузера (`--force-dark-mode`) | оверлей остаётся светлым, текст `rgb(16,16,20)` |
| `<img>` в статьях | **нет ни одной растровой картинки** (только вектор, Метрика и SVG-логотипы вне статей) |

**Две реальные причины, почему у тебя могло оставаться чёрным:**

1. **Устаревший кэш.** CSS и JS подключались без версии (`/styles.css`, `/blog-assets/article.css`).
   После правки браузер мог месяцами отдавать старый файл — и старый оверлей с чёрным фоном.
   **Исправлено:** все стили и скрипты подключаются как `/styles.css?v=<hash>` — версия считается
   из содержимого файла, любая правка меняет адрес и доходит до читателя сразу.
   Контроль: `npm run check` → «расхождений нет», битых ресурсов 0.
2. **Старый деплой.** Правка зума лежала только в репозитории. Ниже — свежий адрес превью.

Дополнительно добавлен жёсткий замок светлой схемы:
`html{color-scheme:light}` + `forced-color-adjust:none` для листа и оверлея — браузер в режиме
высокой контрастности или авто-затемнения больше не может перекрасить схему.

**Отдельно проверен и описан артефакт:** при съёмке экрана **во время плавной прокрутки**
(`scroll-behavior: smooth`) headless-браузер отдаёт чёрную полосу сверху. Это дефект снимка, а не
страницы: при мгновенном переходе к тому же месту кадр чистый (проверено тремя кадрами подряд).
В аудит-скриптах теперь используется мгновенная прокрутка.

признание, что схему поставили не туда, и лишний текст под фигурой. Подпись теперь говорит о том,
что на схеме, а не о том, где её искать.

обратный случай — схема в начале раздела, тянущаяся к предыдущему):
