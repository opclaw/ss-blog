### 3.3 Два пути выкатки

**Путь 1. Кнопка в GitHub (рекомендую).** После мёрджа PR #3: Actions → `site.yml` → «Run
workflow» → ветка `main` → галка **«Выложить сборку на прод»**. Сборка, проверки, rsync,
проверка прода и IndexNow пройдут на серверах GitHub.

Для этого нужны секреты репозитория: `BEGET_USER`, `BEGET_HOST`, `BEGET_PATH`
(и `BEGET_SSH_KEY` + `BEGET_PORT`, если вход по ключу). **Проверить их наличие я не могу** —
у интеграции нет доступа к секретам (403). Посмотрите:
`github.com/opclaw/ss-blog/settings/secrets/actions`.

**Путь 2. Из консоли.** `cd site && BEGET_USER=… BEGET_HOST=… BEGET_PATH=… ./release.sh`
(есть `--dry-run` и `--skip-rsync`). Шаги внутри: зависимости → сборка со всеми проверками →
показ объёма → rsync с `--delete` (`.well-known` не трогает) → `verify-prod.py` → IndexNow.

### 3.4 Чек-лист выкатки

**До:** мёрдж PR #3 в `main` → секреты `BEGET_*` на месте → решение по шрифтам и целям Метрики
(можно и после, но лучше заодно).

**Во время:** галка «Выложить сборку на прод» → смотреть лог: сборка зелёная, rsync прошёл,
`verify-prod.py` ответил «все URL 200, заголовки совпадают».

**После (руками, ~5 минут):** переотправить `sitemap.xml` в Вебмастере → 5 адресов на переобход →
проверить «Диагностику» → проверить, что цели Метрики считаются → записать дату релиза.

Входить в ваши панели (Vercel, Beget, Вебмастер, Метрика), подтверждать наличие секретов,

сборка, проверки, подготовка, выкладка по команде — на мне.
