**Объём:** 120+ статей — это впечатляющий масштаб. Контент покрывает:
- **Фундаментальные гайды:** «Что такое генеративный ИИ», «Искусственный интеллект для бизнеса в 2026»
- **Технические темы:** «ИИ-агенты», «Локальный vs облачный ИИ», «GigaChat vs YandexGPT»
- **SEO-кластер:** 10+ статей про SEO-блог, контекстную рекламу, индексацию
- **Нишевые статьи:** Ресторан, строительство, недвижимость, медицина, юриспруденция
- **Практические гайды:** Промпты, автоматизация документов, чат-боты, переводы
- **Управленческие:** Страх сотрудников, обучение команды, экономия подписок

**Структура URL-ов (семантическая):**
- `/blog/chto-takoe-generativnyy-ii/` — транслит ключевых слов
- `/blog/ii-dlya-restorana-privlechenie-gostey/` — полный ключ
- `/blog/kak-avtomatizirovat-dokumenty-kompanii-s-pomoshchyu-ii/` — long-tail ключ
- `/blog/skolko-stoit-razrabotka-chat-bota-s-ii/` — коммерческий ключ

**Ключевые паттерны:**
- Заголовки начинаются с «Как», «Что», «Почему», «Сколько» — соответствует поисковым запросам
- Каждая статья — отдельный запросный кластер
- Есть кластеры по 5-8 статей на одну тему (ИИ-агенты, SEO-блог)

### 2. SEO-оптимизация (техническая)

**robots.txt — ЭТАЛОННЫЙ:**
```
User-agent: OAI-SearchBot → Allow
User-agent: GPTBot → Allow
User-agent: PerplexityBot → Allow
User-agent: ClaudeBot → Allow
User-agent: Claude-SearchBot → Allow
User-agent: YandexAdditional → Allow
Clean-param: utm_source&utm_medium&utm_campaign...
Sitemap: указан
```

**Что это значит:**
- Сайт разрешает индексацию AI-поисковикам (ChatGPT, Perplexity, Claude)
- Это GEO-оптимизация на техническом уровне
- Clean-param убирает дубли от UTM-меток

**Sitemap.xml:**
- Указаны даты модификации для каждой страницы
- Включены ВСЕ подстраницы блога, рубрики, страницы пагинации
- Все страницы с 2026-09-23 — свежая индексация

### 3. Качество контента

**Сильные стороны:**
- Каждая статья — 8-16 минут, достаточная глубина
- Практические примеры и упражнения
- Таблицы сравнения (модели любят цитировать)
- FAQ-блоки
- Внутренние ссылки на связанные статьи
- Конкретные сценарии для отраслей
- Чёткая структура H2 → H3

**Слабые стороны:**
- Многие статьи выглядят AI-сгенерированными (одинаковый тон, структура)
- Нет реальных кейсов с цифрами клиентов (в основном обобщённые сценарии)
- Отсутствие экспертных интервью, цитат, мнений
- Минимум уникальных данных (нет собственных исследований)
- Повторяющиеся вводные формулировки

### 4. Потенциал трафика (оценка семантики)

**Расчёт потенциального количества запросов:**

При 120+ статьях, покрывающих темы:
- Информационные запросы: «что такое ИИ», «как внедрить ИИ» — 10K-50K запросов/мес
- Коммерческие запросы: «внедрение ИИ цена», «ИИ для бизнеса стоимость» — 2K-10K/мес
- Нишевые запросы: «ИИ для ресторана», «ИИ для юристов» — 500-3K/мес каждый
- Long-tail: «как автоматизировать документы ИИ», «как написать промпт» — 100-1K каждый

**Оценка потенциального органического трафика:**
- При полном индексировании и устоявшихся позициях: **5,000-20,000 органических визитов/мес**
- Текущая оценка (сайт молодой, ~3 месяца): **500-2,000 визитов/мес**
- Через 6-12 месяцев при стабильной публикации: **15,000-50,000 визитов/мес**
