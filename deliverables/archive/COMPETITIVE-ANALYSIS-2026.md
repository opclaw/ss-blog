## 🎯 ПРАВИЛЬНАЯ СТРАТЕГИЯ (по частотности)

### Стратегия «СНИЗУ ВВЕРХ» — единственная реалистичная

```
Фаза 1 (мес 1-2): Низкочастотные (100-500/мес)
   → Быстрые победы, первые позиции, первый трафик
   → 15-20 статей

Фаза 2 (мес 2-4): Средне-низкие (500-2 000/мес)
   → Нарастающий трафик, рост авторитета
   → 15-20 статей

Фаза 3 (мес 4-6): Средние (2 000-5 000/мес)
   → Заметный трафик, конкуренция с детистовым
   → 10-15 статей

Фаза 4 (мес 6+): Высокие (5 000+/мес)
   → Только при набранном авторитете домена
   → 5-10 статей
```

### Почему это работает:
1. **НЧ-запросы** — мало конкурентов, легко попасть в топ-3
2. Каждая НЧ-статья приносит **50-300 визитов/мес** — суммарно это уже заметный трафик
3. Поисковики видят **регулярный качественный контент** → растёт авторитет домена
4. Через 3-4 месяца можно пробиваться в **СЧ-запросы**
5. **ВЧ** — только через 6+ месяцев, при условии стабильной публикации

## 🔑 ВАЖНЕЙШИЕ ВЫВОДЫ

### 1. Мы НЕ можем конкурировать с гигантами напрямую
Хабр, vc.ru, Битрикс24, Сбер — они займут топ по ВЧ-запросам. Наша стратегия — **обходить их через НЧ и специализацию**.

### 2. Detistov.ru — наш прямой конкурент
У него 120+ статей и хороший SEO. У нас — 20 статей, но есть реальные кейсы и экспертиза. **Мы можем его обогнать за 6 месяцев**, если:
- Пишем 7+ статей в неделю
- Качество выше (таблицы, промпты, примеры)
- Подключаем уникальные данные (кейсы)

### 3. НЧ — наш фундамент
15-20 статей по НЧ-запросам = первый трафик + рост авторитета домена. Без этого бессмысленно лезть в СЧ и ВЧ.

### 4. Текущие статьи нужно переписывать
Не удалять, а переписывать — добавлять таблицы, code-блоки, FAQ, внутренние ссылки. Светлая тема для блога.

### 5. API-ключ нужен для точной семантики
Без Wordstat мы работаем «по ощущениям». С ним — точно знаем, какие запросы приносят трафик. Найдите folderId в консоли Yandex Cloud.
