# Промпт для сбора семантики в другой сессии

Как пользоваться:
1. Откройте новую сессию агента, у которой есть доступ в интернет.
2. Скопируйте туда всё, что ниже линии, **вместе с API-ключом** (в этот файл ключ специально не записан).
3. Скачайте готовый файл `semantics.md` и принесите его в эту сессию.

---

## ЗАДАЧА

Собери семантическое ядро для B2B-блога Smart Solutions о внедрении ИИ в бизнес (ЦА — собственники и руководители малого и среднего бизнеса в России). Источник данных — **Yandex Wordstat через Yandex Cloud Search API v2**. Ничего не выдумывай: каждая цифра должна быть из ответа API.

## ДОСТУП

- API-ключ: `<ВСТАВЬТЕ_КЛЮЧ>`
- folderId: `b1gdsts98pr6khbhf5u9`
- Авторизация: заголовок `Authorization: Api-Key <ключ>`
- Документация: https://yandex.cloud/ru/docs/search-api/concepts/wordstat

Эндпоинты (POST, JSON):
- `https://searchapi.api.cloud.yandex.net/v2/wordstat/topRequests` — тело:
  `{"folderId":"b1gdsts98pr6khbhf5u9","phrase":"<фраза>","numPhrases":50,"regions":["225"],"devices":["DEVICE_ALL"]}`
  Возвращает `totalCount`, `results` (вложенные запросы), `associations` (похожие).
- `https://searchapi.api.cloud.yandex.net/v2/wordstat/dynamics` — динамика по месяцам за последние 12 месяцев (`period: PERIOD_MONTHLY`).

Регион **225 = вся Россия** (213 — только Москва, не используй).
Делай паузу ~0.5 с между запросами. При ошибке 403 — остановись и напиши текст ошибки (скорее всего, нет роли у сервисного аккаунта). Если API у тебя недоступен — прямо сообщи об этом, **не подставляй оценки из статей**.

## ШАГ 2. Расширение

Из вложенных запросов и associations отбери **новые** фразы, которые (а) интересны руководителю бизнеса, (б) имеют частотность ≥ 30. Выкинь: мусор, навигационные запросы брендов, «скачать/бесплатно онлайн/на телефон/порно/реферат», учебные и развлекательные запросы. Для новых фраз, которые выглядят как темы статей, сними `totalCount` отдельно.

## ШАГ 3. Динамика

Для топ-30 фраз из нашей ЦА сними `dynamics` за 12 месяцев и отметь: растёт / стабильно / падает.

## ШАГ 4. Кластеризация и итог

Сгруппируй всё в кластеры (одна статья = одна группа запросов с одним интентом). Для каждой группы укажи:
- главный запрос и его частотность;
- 3–10 дополнительных запросов для той же статьи;
- тип частотности: ВЧ (>10 000), СЧ (1 000–10 000), НЧ (<1 000);
- интент: информационный / коммерческий;
- тренд;
- предлагаемый заголовок статьи.

## ФОРМАТ РЕЗУЛЬТАТА — один файл `semantics.md`

```
# Семантика Smart Solutions — <дата>, регион 225
## 1. Сырые данные
| Фраза | totalCount | Тренд 12 мес | Кластер |
## 2. Новые фразы из расширения
| Фраза | totalCount | Откуда (маркер) |
## 3. Кластеры → статьи
### <Кластер>
| Заголовок статьи | Главный запрос | Частотность | Доп. запросы | ВЧ/СЧ/НЧ | Интент | Тренд |
## 4. Топ-20 НЧ/СЧ-тем с низкой конкуренцией для старта
## 5. Что не удалось собрать (ошибки, пустые ответы)
```

Дополнительно приложи `wordstat-raw.json` с полными ответами API.
