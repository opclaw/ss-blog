## Приложение: команды

```bash
cd site
npm run check      # сборка + сверка с эталоном + sitemap + JS + интерактив + SEO-аудит (перед деплоем)
npm run audit      # только SEO-аудит: что ещё стоит поправить
npm run sitemap    # пересобрать sitemap.xml из готовых страниц
npm run dev        # локальный сайт для правок
./deploy-vercel.sh # превью на Vercel (нужен VERCEL_TOKEN)
```

Выгрузка на Beget — содержимое `site/dist/`:

```bash
rsync -avz --delete site/dist/ USER@HOST:~/smartsolutions.today/public_html/
```

## 10. Обновлённый порядок работ (с учётом раунда 2)

1. **Блокеры владельца:** отозвать токен бота, дать доступы Beget.

## 11. Как проверять себя дальше (инструменты в репозитории)

```bash
cd site
npm run check     # всё: сборка, сверка, sitemap, JS, интерактив, доступность, SEO-аудит
npm run qa        # доступность и целостность разметки, якоря, контакты, типографика
npm run content   # контент-аудит: время чтения, структура, повторы, цифры, путь к заявке
npm run audit     # SEO-аудит: мета, схемы, вес, robots/sitemap/.htaccess
npm run sitemap   # пересобрать карту сайта
```

Правило для новых статей: пока `npm run check` не зелёный — статья не публикуется.
