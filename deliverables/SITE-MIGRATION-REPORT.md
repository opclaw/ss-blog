# Перенос smartsolutions.today на Astro — отчёт команд

Дата: 2026-09-25. Источник: архив `version 4.zip` (распакован в `legacy/version-4/`, 90 файлов).
Результат: `site/` — Astro 7.3.5, 27 страниц, статичная сборка с теми же адресами.

## Архитектор: решения

| Вопрос | Решение | Почему |
|---|---|---|
| Движок | **Astro**, `output: static`, `build.format: preserve` | На выходе те же `/services.html`, `/blog/ii-dlya-hr.html`, `/blog/index.html` → SEO-адреса не меняются, хостинг тот же (Beget) |
| Общие части | Компоненты `Nav`, `MobileMenu`, `Footer`, `ContactCards`, `Metrika` + каркас `Base` | Было 5 вариантов шапки, 5 мобильного меню, 5 подвалов — теперь один источник |
| Данные | `src/data/site.ts`: телефон, почта, Telegram, WhatsApp, адрес, меню, ID Метрики | Меняется в одном месте на всех страницах |
| Контент страниц | Перенесён как есть в `src/pages/**.astro` | Ни одна фраза, схема или FAQ не переписаны |
| Стили и скрипты | `styles.css`, `script.js`, `icons.svg` — без изменений в `public/` | Внешний вид и поведение 1:1 |
| Проверка | `npm run check` = сборка + сверка с оригиналом + прогон JS | Любая регрессия ловится до деплоя, также в GitHub Actions |

Рассмотренные альтернативы: Eleventy (проще, но слабее компоненты и типизация), чистый HTML с
подстановкой шапки скриптом (минимум изменений, но дальше развивать неудобно).

## Команда критиков: что ещё найдено (не исправлено — нужно ваше решение)

0. **СРОЧНО: токен Telegram-бота в открытом доступе.** `send.php` содержит токен бота, архив
   `version 4.zip` с ним закоммичен (b3d783c), репозиторий публичный. Отозвать: @BotFather → /mybots →
   бот → API Token → Revoke current token. В `legacy/version-4/send.php` токен заменён на `getenv('TG_BOT_TOKEN')`,
   в сборку сайта `send.php` не попадает.

1. **Яндекс.Метрика стоит на всех страницах** (счётчик 106747750), а в `CLAUDE.md` записан отказ от неё.
   Сейчас сохранена как на сайте. Отключить: `metrikaId: null` в `src/data/site.ts`.
2. **Меню статей подсвечивает «AI»**, а пункта «Блог» в шапке нет — читатель блога не видит, где он.
   Перенесено как есть (навигацию главной без согласования не меняем).
3. **`robots.txt`** закрывает `/consent.html` и `/consent-cookies.html`, которых больше нет, и содержит
   директиву `Host`, которую Яндекс не использует с 2018 года; правило `Disallow: /*.json$` закрывает и `manifest.json`. Безвредно, но можно почистить.
4. **`sitemap.xml`** ведётся вручную. Можно генерировать из страниц автоматически (`@astrojs/sitemap`),
   чтобы новые статьи не забывались.
5. **Внутренний документ `business-strategy-2026.md` лежал в папке сайта.** `.htaccess` запрещает `.md`,
   но в новую сборку он не попадает вообще. Проверьте, нет ли его на хостинге.
6. **Шрифты грузятся с Google Fonts.** Из России бывает медленно; можно положить шрифты на свой хостинг.
7. **Картинки в `images/` весят до 2,3 МБ** (`chaika-cover.png`). Astro умеет сжимать их при сборке
   (WebP/AVIF) — заметно ускорит главную.

## Что не удалось проверить здесь
Скриншоты: из песочницы не скачивается браузер (закрыты CDN Playwright и репозитории Debian).
Внешний вид гарантирован тем, что `styles.css`, `script.js` и разметка контента не менялись,
а шапка/меню/подвал собраны из разметки главной 1:1. Визуально сверить стоит 3 страницы:
главную, любую статью и мобильную версию меню.

## Как продолжать
См. `site/README.md`. Коротко: `cd site && npm install && npm run dev`; перед деплоем `npm run check`;
заливаем `site/dist/`.

## Что нашёл аудит помимо этого (и что сделано)

1. **`.htaccess`: правило против старых `/?p=123` не работало** — `RewriteRule` не видит query string.
   Заменено на `RewriteCond %{QUERY_STRING} (^|&)p=\d+`.
2. **`.htaccess` закрывал `manifest.json`** (запрет `\.(md|json|jsonl)$`) — файл нужен браузеру. Добавлено исключение.
3. **`ai.html`: не было карточки новой статьи** «Что такое ИИ-агент», а счётчик отраслей показывал (11) при 12 карточках. Исправлено: карточка добавлена, счётчик — (12).
4. **Статья «ИИ для продаж» — единственная с блоком «Основное»** вместо «Коротко». Приведено к общему виду.
5. **Три статьи без входящих ссылок** из других статей: «ИИ для HR», «ИИ для медцентра», «ИИ для недвижимости» — задача для внутренней перелинковки (план).
6. **Схемы нет на 5 страницах** (главная, услуги, AI-хаб, 3 кейса — кроме статей блога): нет `Organization`/`Service`/`BreadcrumbList` (план).
7. **9 title длиннее 60 символов** — обрезаются в выдаче (план, нужен ваш выбор).
8. **`MODEL-ROUTING.md`, на который ссылается `CLAUDE.md`, в репозитории отсутствует** — правило в `CLAUDE.md` поправлено, файл стоит восстановить.
