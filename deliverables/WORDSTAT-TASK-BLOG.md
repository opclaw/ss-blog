# Wordstat для переработки блога — два способа

## Способ 1. Скрипт (40 секунд, точные цифры)

На своём компьютере, в папке с файлом `deliverables/wordstat-blog-rework.py`:

```bash
export YANDEX_API_KEY="ваш ключ"          # ключ в файл не вписывать и в репозиторий не коммитить
export YANDEX_FOLDER_ID="b1gdsts98pr6khbhf5u9"
python3 wordstat-blog-rework.py
```

Получится `wordstat-blog-rework.csv` и `.json` — пришлите любой из них в чат или положите в репозиторий.

## Способ 2. Задание для нейросети с доступом к браузеру

Скопируйте целиком:

```

Для каждого запроса из списка ниже:
1. Введи запрос, запиши число показов в месяц (верхняя строка «Число запросов»).
2. Выпиши 5 самых частотных уточнений из левой колонки с их числами.
3. Открой вкладку «Динамика» и запиши, растёт спрос за полгода, падает или стоит (и на сколько процентов примерно).

Ничего не округляй и не додумывай: если цифру не видно — напиши «нет данных».
Результат — одна таблица: запрос | показов/мес | динамика | топ-5 уточнений (запрос — число).
```

## Что решим по этим цифрам
- Юристы: ищут сервисы или автоматизацию фирмы — от этого зависит, о чём переписываем статью.
- Ресторан, логистика, строительство, производство: в заголовок «ИИ для…» или «Автоматизация…».
- Медцентр: «ии для клиники» / «ии для медицинского центра» вместо широкого «ии в медицине».
- Отрасли со спросом около нуля: не переписываем отдельно, а объединяем или переводим в посадочные.
