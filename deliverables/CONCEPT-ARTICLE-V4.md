# Концепция статьи v4 — разбор командой

## Что на самом деле есть на сайте (изучено по styles.css, 12 частей)
- Весь сайт тёмный: фон `#08080D`, текст `#F5F5F7`, акцент `#00D9FF`, второй акцент `#10B981`. Заголовки Manrope 800, текст Inter, подписи JetBrains Mono.
- Шапка `.nav`: фиксированная, полупрозрачная с размытием; логотип текстом «Smart Solutions»; ссылки 14px приглушённые; телефон; бургер на мобильных. Главная кнопка сайта — **белая** (`.btn-primary`), не бирюзовая.
- Низ страницы — `.section-cta`: «Разберём ваш процесс?» + 4 карточки контактов с иконками + строка «Берём ограниченное число внедрений…».
- **У блога уже есть система статьи:** 3 колонки на десктопе (оглавление 220px · текст · карточка автора с контактами 280px), `.fig` с моно-подписью, `.pull-quote`, `.tldr`, `.formula-card`, таблицы с бирюзовой шапкой, FAQ, `.related-card`.
- Принцип из комментария в CSS раздела AI: «плотная крупная типографика, моноширинные номера, строки вместо одинаковых карточек, без свечений и градиентов».

**Вывод:** v1–v3 были ошибкой концепции. Я рисовал новый светлый блог, а нужно довести до совершенства существующий.

## Команда
| Роль | Позиция |
|---|---|
| Арт-директор | Блог — часть бренда. Тёмный по умолчанию, как весь сайт. Никаких новых стилей: только язык сайта (моно-номера, строки, `.fig`). |
| Типограф (UI) | Текущая проблема чтения не в тёмном фоне, а в цифрах: основной текст 16px цветом 60% белого, строка до 720px (~85 знаков), каждый блок в рамке. Это утомляет. |
| UX-исследователь | Длинный текст читают «островками»: заголовок → первая фраза → схема. Нужны сильные якоря: номера разделов, выносная мысль, схема, а между ними — спокойный текст. |
| Эстет | Приятность — это воздух, ритм и тишина. Убрать всё, что шумит: рамки вокруг каждого блока, 4 контакта сбоку, анимации появления текста. Дать опцию «светлый лист» для тех, кто читает долго или днём. |
| Критик (адвокат дьявола) | Светлый режим по умолчанию — снова ломаем бренд. Переключатель — только опция, запоминается. Сбоку не должно быть «продажи» — одна тихая кнопка. И не выдумывать компоненты, которых нет на сайте. |
| Доступность | Контраст основного текста 60% белого ≈ 7:1 — формально ок, но для длинного чтения мало. 82% ≈ 14:1. Размер ≥ 18px. Фокус видимый. Уважать `prefers-reduced-motion`. |
| SEO/GEO | «Коротко» — в начале (цитируют Нейро и ChatGPT), разметка FAQ, живой опыт автора. |

## Решения v4
1. **Тёмная тема по умолчанию**, шапка и блок контактов — реальные классы и реальный `styles.css` сайта (в превью подключён прямо с smartsolutions.today).
2. **Типографика чтения** (файл-заплатка `reading.css` поверх `styles.css`):
   - текст 18px / 1.7, цвет 82% белого; строка ≤ 64 знаков;
   - `text-wrap: pretty`, переносы для русского, висячая пунктуация;
   - заголовки разделов с моно-номером «01 /», как на ai.html;
   - меньше рамок: «Коротко» и врезки — линией слева, не карточкой.
3. **Три колонки как на сайте**, но спокойнее: слева оглавление + «осталось ~N мин»; справа автор (фото, имя, одна строка) и одна кнопка «Обсудить процесс» + Telegram текстом — вместо четырёх контактов.
4. **Схемы — SVG в стиле `.fig`** сайта (моно-подписи, бирюзовые узлы), с увеличением по клику, как уже работает на сайте.
5. **Переключатель «Светлый лист»** (Aa) — тёплая бумага `#F6F4EF`, графит `#1B1C20`, бирюзовый затемнён. Запоминается.
6. **Никаких анимаций текста.** Только прогресс чтения (есть на сайте) и подсветка раздела.
7. **Честный контент:** плашки «нужно от Олега» остаются, пока нет реальных фактов и фото.
