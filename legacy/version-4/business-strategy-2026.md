# Бизнес-стратегия Smart Solutions: Рост среднего чека до 700к-1М ₽

> **Статус:** План утверждён. Реализация отложена.
> **Ключевые решения из обсуждения:**
> - "Ретейнер" → "Сопровождение" (понятнее для рус. клиента)
> - Один продукт "Сопровождение" с 2 пакетами (Базовое от 50к, Расширенное от 100к)
> - Цены — показывать "от ___", не фиксированные
> - Партнёрство — мягко упомянуть как возможность, НЕ как продукт
> - Кейсы — переписать из старого сайта, фокус на результатах
> - Порядок: 1) Обновить главную 2) Страница услуг 3) Кейсы 4) О студии
>
> **Файл для сохранения:** `/version 3/business-strategy-2026.md`

## ФАЗА 1: DISCOVERY

### 1.1 Анализ рынка веб-разработки России 2025-2026

**Сегментация по чеку:**
| Сегмент | Чек | Типичный исполнитель |
|---------|-----|---------------------|
| Массовый | 30-100к ₽ | Фрилансеры, конструкторы |
| Средний | 150-400к ₽ | Небольшие студии ← **Smart Solutions сейчас** |
| Премиум | 500к-1.5М ₽ | Средние студии, агентства |
| Enterprise | 1.5-10М+ ₽ | Топ-студии (AGIMA, Nimax, Лебедев) |

**Ключевой инсайт:** Между средним и премиум сегментом — "долина смерти". Клиенты либо ищут "подешевле", либо идут в топ-студии за "гарантиями". Мало кто готов платить 700к+ небольшой команде без имени.

**Динамика рынка:**
- Рост цен на 20-30% за год (инфляция + усложнение проектов)
- Региональные студии конкурируют с московскими
- Рейтинги на Яндекс Картах дают +60% заявок при оценке >4.5
- AI-инструменты снижают стоимость типовых проектов

### 1.2 Конкурентный ландшафт

**Топ-студии (ориентир по позиционированию):**

| Студия | Мин. чек | Позиционирование | Сила |
|--------|----------|------------------|------|
| Студия Лебедева | ~3М ₽ | "Долго. Дорого. Охуенно" | Бренд, история |
| AGIMA | ~1М ₽ | "Крупнейший интегратор digital-решений" | Масштаб, команда |
| Nimax | Time & Material | "Brand experience agency" | Системность, процессы |

**Что они делают иначе:**
- Работают с брендами, а не просто сайтами
- Продают результат/трансформацию, не часы
- Имеют публичную экспертизу (статьи, выступления, кейсы)
- Отказываются от проектов ниже порога

**Smart Solutions — текущее позиционирование:**
"Разработка сайтов на основе исследований. Сначала изучаем рынок, конкурентов и клиентов."

**Сильные стороны:**
- Уникальный процесс (исследования до разработки)
- Гарантия результата (возврат денег)
- Глубокое погружение (небольшая команда)
- Реальные кейсы с метриками (CND-Store +340% ROI, Моя Планета ×33 трафик)

**Слабые стороны:**
- Нет публичного лица/эксперта
- Кейсы без детализации процесса
- Нет специализации по отрасли
- Позиционирование размыто ("исследования" — непонятно для клиента)

### 1.3 JTBD-анализ целевого клиента

**Текущий клиент (200-400к):**
- Малый бизнес, ИП, стартапы
- Main Job: "Получить сайт, который приносит заявки"
- Покупает: исполнение, результат
- Выбирает по: сарафан, портфолио, цена

**Целевой клиент (700к-1М):**
- Средний бизнес, директор по маркетингу, собственник с оборотом 50М+/год
- Main Job: "Решить бизнес-задачу через digital без лишних рисков"
- Покупает: уверенность, экспертизу, снятие ответственности
- Выбирает по: репутация, кейсы в отрасли, процесс, гарантии

**Job Map целевого клиента:**

| Этап | Что делает | Боль | Возможность |
|------|-----------|------|-------------|
| Define | Понимает, что сайт не работает | "Маркетинг виноват? Продукт? Сайт?" | Аудит/диагностика |
| Locate | Ищет подрядчика | "Все одинаковые, непонятно кого выбрать" | Четкое позиционирование |
| Prepare | Формирует ТЗ, бюджет | "Не знаю, что включить, сколько платить" | Консультация + roadmap |
| Confirm | Убеждается в выборе | "А вдруг не получится?" | Гарантии, пилот |
| Execute | Работает с подрядчиком | "Сколько итераций? Когда результат?" | Прозрачный процесс |
| Monitor | Следит за процессом | "Что происходит? Мы в графике?" | Дашборд, отчеты |
| Modify | Вносит правки | "Это дорого? Долго?" | Гибкость |
| Conclude | Оценивает результат | "Окупится ли?" | ROI-отчет |

**Forces of Progress (почему переключаются на дорогих):**

```
PUSH (выталкивание от дешёвых):
• Уже "обожглись" с фрилансером/дешёвой студией
• Результата нет, деньги потрачены
• Нет времени на переделки

PULL (притяжение к дорогим):
• Хотят "сделать один раз и хорошо"
• Видят кейсы с результатами
• Доверяют процессу/методологии

HABIT (держит у дешёвых):
• "Всегда так делали"
• "Это же просто сайт"

ANXIETY (страх перед дорогими):
• "А вдруг разницы не будет?"
• "Слишком дорого для нас"
• "Не уверен, что стоит своих денег"
```

**Ключевой инсайт:** Клиенты с чеком 700к+ уже обжигались с дешёвыми подрядчиками. Они платят за **уверенность** и **снятие ответственности**, не за часы работы.

## ФАЗА 2: ГИПОТЕЗЫ РОСТА ЧЕКА

### Гипотеза 1: Специализация по отрасли

**Идея:** Выбрать 1-2 отрасли и стать №1 в них.

**Кандидаты (на основе портфолио):**
- E-commerce (CND-Store, mkuksa, Blaxbe)
- B2B/услуги (Arhgrille, Авторад)
- Медиа/контент (Моя Планета, Эксмо)

**Почему работает:**
- Клиент ищет "студию для e-commerce", а не "студию"
- Можно накопить отраслевую экспертизу
- Выше средний чек за счёт понимания ниши
- SEO по отраслевым запросам

**Риски:**
- Сужение воронки
- Зависимость от одной отрасли

### Гипотеза 2: Продуктизация услуг

**Идея:** Создать "коробочные" продукты с фиксированной ценой и объёмом.

**Пример линейки:**
| Продукт | Чек | Что входит |
|---------|-----|------------|
| Аудит | 100-150к | Исследование + roadmap (без разработки) |
| Лендинг PRO | 300-400к | Исследование + лендинг + запуск |
| Корпоративный PRO | 500-700к | Полный цикл + 3 мес. поддержки |
| E-commerce Трансформация | 1-1.5М | Исследование + редизайн + интеграции + 6 мес. |

**Почему работает:**
- Клиенту проще сравнивать и выбирать
- Снижает anxiety ("понятно, что получу")
- Позволяет продавать апсейл
- Упрощает продажи

**Риски:**
- Сложно стандартизировать исследования
- Может конфликтовать с глубоким погружением

### Гипотеза 3: Сопровождение + партнёрство ⭐ ВЫБРАНО

**Идея:** После запуска переходить на сопровождение (поддержка, аналитика, развитие).

**Модель:**
1. Проект 400-700к (разработка)
2. Сопровождение от 50-100к/мес (поддержка, аналитика, итерации)
3. Через 6-12 мес. — партнёрство (% от результата) — как возможность для лучших клиентов

**Почему работает:**
- LTV клиента растёт в 3-5 раз
- Предсказуемый доход
- Глубокие отношения → сарафан
- Уже описано на сайте ("партнёрство")

**Риски:**
- Требует других компетенций (маркетинг, реклама)
- Нужна команда для поддержки

### Гипотеза 4: Публичная экспертиза

**Идея:** Стать публичным экспертом в "исследованиях перед разработкой".

**Тактики:**
- Статьи на VC.ru, Habr про методологию
- Кейсы с детальным описанием процесса
- Telegram-канал / YouTube
- Выступления на конференциях
- Курс/вебинар "Как заказать сайт, который работает"

**Почему работает:**
- Создаёт доверие до первого контакта
- Привлекает "тёплых" лидов
- Отстраивает от конкурентов
- Обосновывает премиальный чек

**Риски:**
- Требует времени на контент
- Результат отложенный (6-12 мес.)

## ФАЗА 3: РЕКОМЕНДУЕМАЯ СТРАТЕГИЯ

### Приоритет: Сопровождение + Партнёрство

Эта модель выбрана как основная стратегия роста чека.

**Почему это работает для Smart Solutions:**
- Уже есть на сайте ("партнёрство вырастает из совместной работы")
- Соответствует ценностям (глубокое погружение, долгосрочные отношения)
- Клиенты по сарафану — это уже доверие, легко переводить на сопровождение
- LTV клиента растёт в 5-10 раз

**Модель монетизации:**

```
ЭТАП 1: Проект (разовый)
├── Исследование + сайт: 400-700к
├── Срок: 6-10 недель
└── Результат: работающий сайт с первыми заявками

ЭТАП 2: Сопровождение (ежемесячное)
├── Базовое: от 50 000 ₽/мес
│   └── Поддержка, аналитика, мелкие доработки
├── Расширенное: от 100 000 ₽/мес
│   └── + Контекстная реклама / SEO / A/B-тесты
└── Срок: от 6 мес.

ЭТАП 3: Партнёрство (возможность, не продукт)
├── Условие: 6+ мес. успешного сопровождения + доверие
├── Модель: фикс + % от выручки/заявок
└── Упоминать мягко как перспективу, не продавать напрямую
```

**Unit Economics сопровождения:**

| Сценарий | Проект | Сопровождение/мес | Срок | LTV клиента |
|----------|--------|-------------------|------|-------------|
| Только проект | 400к | — | — | 400к |
| + Базовое сопровождение | 400к | от 50к | 12 мес | 1М |
| + Расширенное | 500к | от 100к | 18 мес | 2.3М |
| + Партнёрство | 500к | 80к + % | 24+ мес | 3-5М+ |

**Ключевой инсайт:** 1 клиент на долгосрочном сопровождении = 5-10 разовых проектов по LTV.

### Тактический план (6 месяцев)

**Месяц 1-2: Формализация модели**
- [ ] Описать 2 пакета сопровождения (состав, цена "от", SLA)
- [ ] Создать шаблон ежемесячного отчёта для клиента
- [ ] Подготовить договор на сопровождение
- [ ] Определить критерии перехода в партнёрство

**Месяц 2-3: Пилот на новых клиентах**
- [ ] Предложить сопровождение как "следующий шаг" после проекта
- [ ] Запустить пилот, собрать обратную связь
- [ ] Адаптировать модель

**Месяц 3-4: Интеграция в процесс продаж**
- [ ] Обновить презентацию услуг (проект → сопровождение → партнёрство)
- [ ] Добавить на сайт раздел "Сопровождение"
- [ ] Начать предлагать сопровождение на этапе продажи проекта

**Месяц 4-6: Масштабирование**
- [ ] Перевести 30%+ новых клиентов на сопровождение
- [ ] Запустить 1-2 партнёрства (при наличии подходящих клиентов)
- [ ] Нанять человека на поддержку/аналитику (при 4+ клиентах на сопровождении)

### Что нужно для сопровождения

**Компетенции (могут потребовать усиления):**
- Аналитика (Google Analytics, Яндекс.Метрика, тепловые карты)
- A/B-тестирование
- Контекстная реклама (Яндекс.Директ)
- SEO (базовый уровень)
- CRM-интеграции

**Инструменты:**
- Дашборд для клиента (Google Data Studio / Яндекс.Дата)
- Система тикетов для поддержки
- Трекер задач (Notion, Asana)

**Команда:**
- При 4+ клиентах на сопровождении нужен аналитик/маркетолог (50-80к/мес)
- При 8+ — возможно, аккаунт-менеджер

### Привлечение клиентов (без бюджета)

**Ограничение:** Только время, без рекламного бюджета.

**Стратегия:** Контент-маркетинг + активация сарафана

**Канал 1: Контент на VC.ru / Habr (2-4 часа/неделю)**

Темы, которые привлекают целевую аудиторию (директора по маркетингу, собственники):
- "Почему ваш сайт не конвертирует: 5 ошибок, которые мы нашли в 20 проектах"
- "Как мы увеличили ROI рекламы на 340% для интернет-магазина косметики"
- "JTBD-исследование перед редизайном: пошаговый разбор"
- "Сколько стоит сайт, который работает: честный breakdown"
- "Как выбрать подрядчика на разработку сайта (чек-лист от подрядчика)"

**Формат:**
- 1 статья каждые 2 недели
- Детальный разбор с цифрами
- CTA: "Обсудить ваш проект" / "Скачать чек-лист"

**Канал 2: Активация сарафана (1-2 часа/неделю)**

- Написать всем бывшим клиентам: "Как дела с сайтом? Могу помочь с X?"
- Попросить рекомендации: "Есть ли знакомые, кому нужен сайт?"
- Предложить бонус за рекомендацию (скидка на сопровождение, бесплатный аудит)

**Канал 3: Партнёрства с агентствами (2-4 часа/месяц)**

- Крупные студии (AGIMA и др.) отдают мелкие проекты на субподряд
- Маркетинговые агентства ищут подрядчиков на разработку
- Предложить себя как партнёра по разработке

**Где искать:**
- Клуб партнёров AGIMA
- Telegram-чаты веб-разработчиков
- Конференции (бесплатное участие)

**Канал 4: Рейтинги и каталоги (разово)**

- Добавиться в Tagline, Ruward, Рейтинг Рунета
- Заполнить профиль, добавить кейсы
- Поддерживать актуальность

**Канал 5: Telegram-канал (опционально, 2-3 часа/неделю)**

- Короткие посты про исследования и разработку
- Репосты статей
- Закулисье проектов
- Рост: 6-12 месяцев до значимой аудитории

### Воронка привлечения (без бюджета)

```
Статья на VC.ru (охват 5-20к)
        ↓
Переход на сайт (1-3% = 50-600 чел.)
        ↓
Заявка (2-5% = 1-30 заявок)
        ↓
Квалификация (30-50% подходят)
        ↓
Встреча → Продажа (20-30%)
```

**Реалистичные ожидания:**
- 1 статья = 1-3 квалифицированные заявки
- 2 статьи/месяц = 2-6 заявок
- Конверсия в проект: 20-30%
- Итого: 1-2 новых проекта/месяц от контента

### Дополнительные тактики

**Продуктизация (поддержка основной модели)**
- Создать 2 пакета сопровождения с ценами "от"
- Упростить выбор для клиента

**Публичная экспертиза**
- 1-2 статьи на VC.ru в месяц
- Кейсы с результатами сопровождения ("как мы увеличили конверсию на 40% за 6 месяцев")

## ДЕТАЛЬНЫЙ ПЛАН ИЗМЕНЕНИЙ САЙТА

### Текущее состояние

Сайт — качественный лендинг с хорошим дизайном. Но для стратегии "сопровождение + партнёрство" нужно:
- Показать путь клиента: проект → сопровождение → (партнёрство как возможность)
- Обосновать ценность долгосрочного сотрудничества
- Дать понять цены (снять anxiety)
- Показать глубину экспертизы через кейсы

### Структура сайта (было → станет)

```
БЫЛО (1 страница):
└── index.html (лендинг)

СТАНЕТ (5-7 страниц):
├── index.html (лендинг — обновлённый)
├── services.html (услуги и цены)
├── cases/
│   ├── cnd-store.html (детальный кейс)
│   └── moya-planeta.html (детальный кейс)
├── about.html (о студии + команда)
├── blog.html (статьи — опционально, можно VC.ru)
└── contacts.html (или оставить на лендинге)
```
