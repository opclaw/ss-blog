# Wordstat-тематика — Smart Solutions (полный охват, 2 волны)

> Собрано 2026-09-25, Yandex Cloud Search API v2 (`topRequests`), регион 225 (Россия).
> **Волна 1** (`wordstat-theme.json`): 102 запроса — объединение двух старых списков.
> **Волна 2** (`wordstat-wave2.json`): 83 запроса — хвосты из волны 1 + новые подтемы (маркетплейсы, речевая аналитика, документы, DeepSeek и др.).

> Скрипты: `fetch-theme.py` (волна 1), `fetch-wave2.py` (волна 2). Пересбор: `python3 fetch-theme.py && python3 fetch-wave2.py` (env: `YANDEX_SEARCH_API_KEY`, `YANDEX_FOLDER_ID`).

### Наблюдения

1. **ВЧ-запросы «ии агент» (72К) и «нейросеть для текста» (99К)** — это НЕ наш покупатель напрямую, но это трафик-магнит: статьи-объяснения с мягким CTA → перелинковка на услугу.
2. **Юридическая вертикаль (17К/мес)** — самая крупная отраслевая. «Стриж» занимает бренд-позиции, но общие запросы свободны.
3. **«Внедрение ии» 14 613 vs 214 в старой CONTENT-MAP** — старая карта мерила точную фразу «внедрение ии в бизнес» без морфологии. Новые данные в ~65 раз выше.
4. **«Автоматизация производства» (34,5К)** — промышленный интент, скорее не B2B-услуга для нас; лучше через «ии на производстве» (1 853).
5. **DeepSeek (212К)** — крупнейший запрос сбора, но интент «что это/как пользоваться» (B2C). Только как блок в сравнительной статье, не отдельная статья.
6. **Новые B2B-ниши волны 2 без конкурентов в блоге:** документы (4К), речевая аналитика (2,2К), анализ данных (2,2К), Telegram-боты (2,6К), маркетплейсы (3,6К+3,3К) — минимальная конкуренция при платёжеспособном спросе.
7. **«ии для учителя» (13,2К)** — B2C-интент, не наш покупатель. Пропустить, несмотря на объём.
